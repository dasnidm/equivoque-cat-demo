# Equivoque Cat Demo

세 고양이의 선택과 시각적 유지·제거 반응을 이용하는 정적 UI/UX 데모입니다.
HTML, CSS, vanilla JavaScript만 사용하며 빌드나 외부 라이브러리가 필요하지 않습니다.

## 실행

`public/index.html`을 브라우저에서 열거나 `python -m http.server 8765 --directory public`으로 실행합니다.

## 배포

Vercel의 Other 프레임워크로 배포하며 공개되는 사이트 파일은 `public/` 아래의 세 파일입니다.
GitHub 저장소는 비공개입니다. 배포 사이트는 별도의 공개 URL을 갖습니다.

## 원본과 범위

2026-09-20에 research vault의 `70-demo/equivoque-choice-webapp`에서 복사했습니다.
배포 준비 시 원본의 UI와 동작을 변경하지 않았습니다.
이 데모에는 연구용 행동 로그 수집·설문·데이터 저장 기능이 구현되어 있지 않습니다.
기존 모드에는 선택 도중 설명 문구가 없고, 완료 후 결과 문장이 표시됩니다.

## 쓰다듬기 v2 (2026-09-22)

상단 토글로 기존 모드와 v2를 전환합니다. 전환하면 진행 중 선택을 초기화합니다.
v2는 기존 세 고양이의 집합 구성·유지·제외 구조를 공유하며, 쓰다듬기 프레이밍과 SVG 애니메이션만 추가합니다.
고양이는 호흡·꼬리·눈깜빡임으로 잔잔하게 움직이고, 드래그/터치 스와이프 시 고개를 기울입니다.
18px 이상의 누적 이동 후 손을 떼면 한 번의 선택으로 처리합니다. 탭/클릭과 키보드 Enter/Space도 지원합니다.
입력 취소는 선택을 발생시키지 않습니다. 선택 시 동일한 부르르 반응과 테두리·상태 표시를 사용하고,
고양이 제거는 기존 집합 확정 시점의 페이드 방식으로 유지합니다. Reduced motion 설정에서는 반복 애니메이션을 끕니다.
5마리 가변 집합 모델은 이번 UI 버전에 포함하지 않았습니다. 연구용 로그 수집은 아직 없습니다.
